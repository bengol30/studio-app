# מערכת ניהול אולפן – Bengo Productions

אפליקציית Next.js 14 לניהול אולפן הקלטות בקריית שמונה.

## Stack

- **Framework:** Next.js 14 App Router
- **Database:** Supabase (PostgreSQL + RLS)
- **Auth:** Supabase Auth (admin only)
- **Styling:** Tailwind CSS + shadcn/ui + RTL Hebrew (Heebo font)
- **Integrations:** Google Calendar, Make.com (WhatsApp)

## Development

```bash
npm install
npm run dev
```
